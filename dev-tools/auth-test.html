UnitPrep auth harness

Dev-only scratch page for driving the WebAuthn ceremonies by hand. Not product code.
Origin matters. WebAuthn binds a credential to the page's origin, so this page must be loaded from exactly the origin the API was started with as WEBAUTHN_RP_ORIGIN. If they disagree the browser rejects the ceremony before the server ever sees it. Use dev-tools/run-auth-harness.sh, which starts both halves with matching values.
